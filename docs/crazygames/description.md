# Fliptide — listing description (owner's voice; edit freely)

**Short (≤ 100 chars):**
One tap flips gravity. Same course for everyone today — how far did you get?

**Long:**
Fliptide is a one-tap gravity runner. Tap to fall to the ceiling, tap to drop back to the floor,
and thread a corridor of spikes, blocks and pits that's the same for every player in the world
that day. Die and you're back in under a second with a ghost of your best run beside you. When
you're done, share your run as a text card with the course code — a friend can play the exact
course you died on.
