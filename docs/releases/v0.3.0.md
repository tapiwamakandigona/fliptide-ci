# 0.3.0 — First Light

- An original gravity-flip app icon, with adaptive, round and monochrome
  Android variants.
- Six rebuilt Shallows courses teach flips, pits, walls and when to stay
  put. Clear gaps give you time to read, land and decide. Carry the last
  spark from the dark lighthouse toward the first beacon.
- Your earned stars stay. Old Shallows attempt records are kept separately
  because those courses have changed. Daily/shared-code generation is unchanged.
- First-session navigation and Shallows lessons in French, Spanish and
  Brazilian Portuguese. Device language is automatic; the globe on the
  title lets you choose. Store/sharing/later text is only partly translated.
- Roomier text-aware controls and a scrolling title for small screens.
  The menu stops decorative motion with the system reduced-motion setting.
- Menu duration labels no longer generate/solve courses while laying out.
  Animated background paints without rebuilding the title every frame.
