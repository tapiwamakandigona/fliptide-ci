# v0.4.1 (8) "Tidelight": the world outside the corridor

Owner request (2026-09-27): make it look better, smoother and more playable, then send it to Play.

## Player-facing
- **A night coast above, a moonlit sea below.** On a phone in portrait the corridor is about a third of the screen;
  the rest used to be two flat navy slabs. The ceiling now carries a starry sky with a moon, two slow ridges and the
  dark lighthouse from the opening line; the floor sits on a sea with gentle waves and a broken moon glint. Everything
  scrolls at its own parallax depth, so speed reads better.
- **The last spark glows.** The player casts a warm light that also lights the walls near it.
- Floor and ceiling keep a solid crust along the corridor, so the surfaces you run on still read as walls.
- Gameplay, courses, codes, ghosts and saves are unchanged (render-only).

## Engineering notes
- `lib/game/scenery.dart` (new): deterministic (hash-placed stars, camera/clock-driven motion, no runtime RNG), paths
  and shaders rebuilt only on resize, ~20 draw calls per frame (3 batched star calls). Steps aside when a slab is
  thinner than ~0.9 tile (landscape), leaving just the crust.
- `lib/game/flip_game.dart`: slabs → crust (0.55 tile) + scenery; seams limited to the crust; player glow = one cached
  radial shader drawn under the creature, faded with the player's alpha.
- New tests `test/tidelight_scenery_test.dart` (4): portrait draws sky+sea with the moon clear of the player column,
  thin slabs skip scenery, far camera/clock values are safe, 300 portrait frames render. Full suite 201 passed / 3
  skipped; analyze clean.
- Share links: re-checked the old F-SHARE report — `main.dart` already parses `?level=` (and `?code=`), so a shared
  First Light link opens First Light on web.
