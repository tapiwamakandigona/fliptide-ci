# Fliptide 0.2.0 (versionCode 3) — "The Tides"

Fliptide is now a full game, not a daily-only prototype.

## New
- **Title screen** — PLAY (next course), THE TIDES, DAILY #N, COURSE CODE, Supporter,
  and the More-from-Tsoro-Studios footer.
- **The Tides campaign** — 5 tides × 6 authored courses (30 in all) with a designed
  difficulty curve: course length 13 → 28 s, speed 6.5 → 11, hazard tiers 1 → 4.
  Shallows · Drift · Undertow · Riptide · Maelstrom.
- **Stars & progression** — 3★ first try, 2★ within three, 1★ otherwise; best kept;
  the next course unlocks on clear; level-select grid; NEXT on the CLEARED card;
  a ‹ menu button in every run.
- Daily and shared course codes work exactly as before.

## Fixed
- Opening CODE during a run pauses it; cancel resumes the same attempt.
- A Supporter restore arriving during ad initialisation no longer triggers an
  interstitial request; disposed screens never load ads.
- "CLEARED" / percent titles scale down instead of overflowing on 300-px-wide phones;
  HUD course labels ellipsise on 360-px phones; title stats wrap.

## Unchanged
- Supporter (USD 1.99) removes every ad. Ads: one optional rewarded "second chance",
  interstitials only at session breaks. Plays offline; no account.
