# 0.4.0 — "Soundtide": sound, feel, and The Deep

The first update that makes Fliptide *sound* like a game and gives it a
reason to come back that is not the Daily.

## What is new

- **Original soundtrack.** Two loops written for the game: *Undertow*
  (128 BPM, A minor, plays during a run) and *Slack Water* (72 BPM,
  A Dorian, on the title). Both are synthesised in-house from a score
  (`tool/audio/gen_audio.py`), so Tsoro Studios owns them outright — no
  licensed samples, no attribution strings.
- **Seven sound effects.** flip, land, death, clear, star, checkpoint, tap.
  Short, soft, and mastered ~6 dB above the music so they read clearly.
- **Haptics.** A light tick per flip, a firmer bump on death, a thump on a
  clear. Android only (web/desktop have no vibrator).
- **Settings sheet** (gear on the title): Music, Sound effects, Vibration
  switches — all default on, persisted on device — plus Language and a small
  stats block (lifetime flips, deaths, dives, deepest).
- **The Deep — endless mode.** No finish line. A new corridor every dive,
  1,300+ columns long, built from the same chunk pool with tier weights that
  ramp from Shallows-easy to Maelstrom-hard every 48 columns. Score is depth
  in metres (columns survived); the best depth and dive count persist and
  show on the title. Touching the far gate is the secret ending ("THE
  BOTTOM"). Share text: `🌊 143 m · best 201 m · dive 7`. Deep link `?deep=1`.
- **Animation.** CLEARED stars pop in one at a time (elastic, 170 ms apart,
  chimes in step); the title wordmark bobs on a slow swell; title ↔ run
  routes cross-fade instead of sliding. Everything is static under
  reduce-motion / accessible navigation.
- **Performance.** The renderer no longer allocates ~20 `Paint`s, 6 gradient
  shaders and 3 `Path`s per frame: static paints are built once, size-bound
  shaders and spike paths are rebuilt only on resize, particles share one
  paint. VM micro-benchmark (`test/zz_render_bench_test.dart`, software
  canvas, record-only): 222 → 175–185 µs per frame (≈ −19 %). That is a
  proxy for allocation pressure, not a device frame time.

## Unchanged

Sim, physics, course codes, Daily seeds, The Tides, ads/Supporter logic,
signing key, package id. Web builds keep ads/IAP as no-ops.

## Verification

- `flutter analyze`: clean. `flutter test`: **197 passed / 3 pre-existing
  skips** (184 before). New: `test/soundtide_test.dart` (cues, haptic gate,
  settings persistence, star reveal, Deep generator/HUD/dive-again/best).
- Audio QA is by measurement, not by ear: peaks −2.5 / −2.1 dBFS, RMS −14.3 /
  −13.5 dBFS, crest ≈ 11.5 dB, no DC, loop-point jump ≤ 0.008, sample-exact
  loop lengths 15.000 s / 26.667 s. **Owner listen-through is the release
  gate for the music.**

## Tester notes (Play "What's new", ≤ 500 chars)

Fliptide now has sound: an original soundtrack, seven effects and haptics —
all switchable in the new Settings sheet. New mode: THE DEEP, an endless
corridor that gets harder the further you go; your best depth is saved.
Stars now pop in on a clear, and the game draws with fewer allocations per
frame. Progress, Dailies and codes are unchanged.
